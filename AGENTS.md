# AIK working rules

- Work only in this AIK directory.
- Make and verify changes locally first so the user can review them.
- Do not push to GitHub, publish, deploy, or trigger a deployment without an explicit user instruction to publish the reviewed changes.
- The user treats «залити на гіт», «пушити», and «деплоїти» as the same publication process. A request to edit the site does not authorize publication.
