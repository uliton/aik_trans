# AIK — вантажні перевезення

Статичний односторінковий сайт на React + Vite. Усі файли проєкту знаходяться в AIK.

## Локальний запуск

```sh
npm ci
npm run dev
```

`npm run build` створює статичну збірку в `dist/`. `npm run preview` відкриває зібраний сайт.

## GitHub Pages

Remote: https://github.com/uliton/aik_trans.git

Workflow `.github/workflows/deploy.yml` публікує `dist/` після push у `main`. У GitHub → Settings → Pages → Source оберіть **GitHub Actions**. Публікація з поточного комп’ютера потребує авторизації GitHub; додавання remote саме по собі не завантажує файли.

## Форма

Три обов’язкові поля: ім’я (мінімум 2 літери, дозволено літери та пробіли), телефон (9 цифр після окремого префікса +380) і e-mail латиницею, а також обов’язкова згода на обробку даних. Кнопка заблокована, поки форма невалідна, та під час запиту. Нативний dialog підтримує Escape, фокус і закриття поза вікном. Значення `source` вказує, яка кнопка відкрила форму.

Скопіюйте `.env.example` у `.env.local` і задайте `VITE_FORM_ENDPOINT` — публічну HTTPS-адресу приймання JSON. На GitHub задайте її в Settings → Secrets and variables → Actions → **Variables**. Потрібна нова збірка після зміни змінних.

Контракт запиту: POST, Content-Type: application/json:

```json
{"name":"Ім’я","phone":"+380501234567","email":"name@example.com","consent":true,"source":"Замовити перевезення","createdAt":"2026-10-24T12:00:00.000Z"}
```

Endpoint має повертати успішний HTTP 2xx лише після приймання заявки. Потрібно дозволити CORS для домену сайту. Помилки та таймаут 15 секунд відображаються у формі, введені дані зберігаються у відкритій модалці. Без endpoint відображається повідомлення про непідключене надсилання; заявки не імітуються та не зберігаються локально.

### Надсилання до групи Telegram

Рекомендована схема: **GitHub Pages → Cloudflare Worker → Telegram Bot API → група**. Власного постійного сервера не потрібно, але потрібна окрема serverless-функція.

1. Створити бота через @BotFather та додати його в потрібну групу з дозволом надсилати повідомлення.
2. Зберегти токен бота і `chat_id` як серверні секрети Worker.
3. У Worker перевіряти вхідні поля та згоду, обмежувати запити, додати захист від спаму (наприклад Turnstile), дозволити CORS лише для свого домену.
4. Викликати `https://api.telegram.org/bot<TOKEN>/sendMessage` із `chat_id` та текстом заявки; перевіряти відповідь Telegram.
5. Публічну адресу Worker записати у `VITE_FORM_ENDPOINT`.

**Не додавайте токен бота у React, VITE_*, GitHub Variables або публічний репозиторій:** клієнтські змінні потрапляють у JS-збірку. Worker наразі не розгорнутий; вибір приймача заявок залишено відкритим.

Telegram: https://core.telegram.org/bots та https://core.telegram.org/bots/api#sendmessage

## Binotel GetCall

Після реєстрації отримайте офіційний код встановлення віджета. `VITE_BINOTEL_WIDGET_ID` має містити публічний hash із адреси `https://widgets.binotel.com/getcall/widgets/HASH.js`. Доданий завантажувач підключає цей скрипт, після чого плаваючу кнопку і поведінку забезпечує Binotel. Звірте адресу з кодом зі свого кабінету: якщо Binotel змінить формат, скоригуйте завантажувач у `src/main.jsx`. Немає сторонніх приватних API-ключів або вигаданих ідентифікаторів. Без hash показується тимчасова кнопка, що відкриває нашу форму; це не активний сервіс Binotel.

Офіційні інструкції: https://www.binotel.ua/ua/faq

## Що потрібно перед запуском реклами

Підключити приймач заявок, замінити соціальні посилання, перевірити телефон, характеристики та статистику, затвердити текст згоди й інформацію про обробку персональних даних, додати hash Binotel.

## Єдина типографіка

Шкала визначена змінними `--text-*` у `:root` в `src/style.css`:
- Основний текст, описи послуг, характеристики автопарку та переваги: 18 px; на екранах до 580 px — 16 px.
- Навігація, телефон, усі кнопки та поля форми: 16 px на всіх екранах.
- Допоміжні підписи, мітки, підписи форми та згода: 14 px.
- Заголовки карток: 24 px; заголовки розділів мають спільний адаптивний розмір 32–54 px.

Змінюйте спільну роль, коли потрібно змінити розмір тексту. Не додавайте окремі довільні розміри для описів у різних секціях. Сітки та відступи адаптуються під читабельний текст.

Телефон відображається як `+380` поза інпутом і `11 222 33 44` у полі; запит містить повний номер `+380112223344`. Вставлені повні українські номери нормалізуються. Ім’я відкидає цифри та сторонні символи. E-mail приймає лише ASCII-символи без пробілів, перевіряє локальну частину й домен. Введення нелатинських символів блокується з поясненням у формі. Перевірка у браузері не замінює серверну валідацію майбутнього приймача заявок.
